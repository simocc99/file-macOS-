# file-macOS-

Gestore di file nativo per macOS, scritto in SwiftUI.

## Funzioni
- Sfoglia le cartelle partendo dalla home
- Doppio clic per aprire cartelle e file
- Ricerca per nome nella cartella corrente
- Sposta nel Cestino dal menu contestuale

## Compilazione
La build gira su GitHub Actions (`.github/workflows/build.yml`, avvio manuale o push su `main`).
In locale: `swift build` / `swift run`.
